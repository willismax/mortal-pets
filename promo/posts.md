## 巴哈姆特・活俠傳哈啦板

**標題**

【創作】把結緣角色做成 Codex／Claude Code 的桌面寵物（附網頁可玩，微雷）

**內文**

> 非官方同人作品：角色設定整理自公開資料，像素圖和台詞都是自己畫、自己寫的，沒有使用遊戲素材或原文。

各位唐門子弟好！

最近寫程式時常在想，如果小梅在旁邊煮菜、小竹在旁邊打鐵該多好……所以就把活俠傳的結緣角色做成了 AI 寫程式工具（Codex 和 Claude Code）的桌面寵物 XD

（放 promo-landscape.png）

**目前有的角色**
- 小梅：雙手背在身後，打招呼用鶴手，開心就飛踢，搞砸了眨眼吐舌敲頭
- 小竹：打鐵打到一半用手套擦汗；另有「裂骨魔」戰鬥裝（機關臂扛巨劍＋虎頭盾）
- 小師妹：雙手交握、摺紙鶴，迷路時縮著手抖抖抖
- 龍湘：永遠在啃雞腿，開心時拿雞腿當劍刺
- 夏侯蘭：撐著油紙傘，「懶徒兒，跟我來」
- 葉雲裳：欸嘿、嘟嘴、祈禱，鬧太久會發燒倒下

（放 promo-moves.gif）

**怎麼玩**
1. 不用安裝，直接在網頁上玩：https://willismax.github.io/mortal-pets/
   可以摸頭、餵食、練功、送禮、聊天累積好感，好感高了深夜會說心裡話。
2. 用 Claude Code 的人：輸入 `/plugin install mortal-buddy --marketplace willismax/mortal-pets`
   她會跟著你的工作狀態說話：跑指令時陪你、指令失敗時安慰你、完成時誇你。
3. 用 Codex 的人：照 GitHub 上的說明把寵物裝進去，她會依 Codex 的狀態切換九種動畫。

原始碼：https://github.com/willismax/mortal-pets
支援中文、日本語、한국어、English，網頁右上角可以切換。

**關於劇透**
角色檔案裡有幾條劇情雷（小梅、夏侯蘭、葉雲裳的身世），網頁上預設是模糊的，點了才會顯示。

**最後**
造型是對照官方立繪做的像素圖，但每格只有 48×52 像素，有不像的地方歡迎留言抓蟲～
也想知道大家希望下一個做誰（魏菊？唐門師兄們？）

《活俠傳》著作權屬於原始鳥熊（Obb Studio）與發行商 Paras Games，本作品為非營利同人創作。
