Codex 動畫狀態預覽

角色檔案

    帶回家

    Codex：把 資料夾（pet.json、spritesheet.webp）複製到 ~/.codex/pets/，再到 Settings → Pets → Refresh。或在 repo 裡執行：

    cd mortal-pets && ./install.sh codex

    Claude Code：安裝外掛後，她會依你的工作狀態說話，也能用指令互動。

    /plugin install mortal-buddy --marketplace willismax/demo
/mortal-buddy:pick xiaozhu     換寵物
/mortal-buddy:pet feed         摸頭 pet／餵食 feed／練功 train／送禮 gift
/mortal-buddy:talk             聊天（回答用 /mortal-buddy:talk 2）
/mortal-buddy:roleplay 今天好累  讓她用自己的口吻回你

    完整說明見 mortal-pets/README.md。網頁上的好感只存在這個瀏覽器，和 Codex／Claude Code 的好感是分開的。
