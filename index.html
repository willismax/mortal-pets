    帶回家

    Codex：把 資料夾（pet.json、spritesheet.webp）複製到 ~/.codex/pets/，再到 Settings → Pets → Refresh。或把 repo 抓下來執行：

    git clone https://github.com/willismax/mortal-pets.git
cd mortal-pets && ./install.sh codex

    Claude Code：安裝外掛後，她會依你的工作狀態說話，也能用指令互動。
